# Buscador de CEP

Aplicacao CLI em Python que busca enderecos a partir de um CEP usando a API publica ViaCEP.

## Como executar

1. Instale as dependencias:
pip install -r requirements.txt

2. Rode a aplicacao:
python main.py

## Testes

pytest test_api.py -v
